RESOURCE LIBRARY / PRACTICAL NOTES

Useful starting points, not noise.

A growing library of practical references for building and maintaining digital projects. Start with official documentation, test changes carefully and document what you learn.

01 / WEB FOUNDATIONS

HTML, CSS & JavaScript

Use semantic HTML, responsive layouts, accessible controls and clear JavaScript states. Build a small feature, test it on mobile and add useful error messages before adding complexity.

MDN Web Docs ↗

02 / REACT

Component thinking

Split interfaces into reusable components, keep data flow understandable, and make loading, empty, error and success states intentional.

React Learn ↗

03 / API WORK

Integration checklist

Check authentication, rate limits, error responses, CORS, timeouts, data validation and secret handling. Never expose private API keys in client-side code.

HTTP documentation ↗

04 / SEARCH

Technical SEO basics

Give each page a unique title and description, use descriptive headings and links, create a valid sitemap, check canonical URLs and make sure important content is crawlable.

Google SEO Starter Guide ↗

05 / QUALITY

Performance & accessibility

Compress images, avoid unnecessary scripts, use keyboard-friendly controls, maintain contrast and test real phone widths. Measure before and after performance changes.

Web Vitals ↗ · WCAG 2.2 ↗

06 / AI & AUTOMATION

Start with a clear workflow

Define the input, output, failure cases and human review step. Use sample data first and avoid giving automations more access than they need.

Read MBK articles ↗
