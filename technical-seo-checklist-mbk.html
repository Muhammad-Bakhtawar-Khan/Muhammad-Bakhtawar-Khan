Technical SEO Checklist for a Portfolio Website

A practical checklist from Muhammad Bakhtawar Khan (MBK) covering indexing, canonicals, metadata, internal links and structured data.

A portfolio SEO review should check status codes, robots directives, sitemap coverage, canonical URLs, mobile usability, page titles, descriptions, image alt text, internal links and valid structured data. Muhammad Bakhtawar Khan (MBK) uses this portfolio to document practical web and SEO interests. After updates, validate the deployed site, inspect important URLs in search tools and monitor changes rather than assuming that publishing alone creates rankings.
